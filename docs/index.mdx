## The core rule

A task is a three-party contract:

1. **The instruction** tells the agent what result is required.
2. **The environment** makes that work possible without exposing privileged answers.
3. **The verifier** accepts all materially correct results and rejects materially incorrect ones.

The Oracle proves at least one valid solution exists. The NOP baseline proves doing nothing does not pass. Negative and mutation tests establish that plausible wrong answers also fail. Agent trials measure difficulty; they do not substitute for verifier validation.

## What “source-traceable” means

Every policy-sensitive page identifies its authority. Labels are used consistently:

| Label | Meaning |
|---|---|
| **Upstream requirement** | Explicitly required by a benchmark repository, rubric, CI check, or Harbor contract. |
| **Deaimer standard** | Our stronger internal default for reducing review risk. |
| **Recommendation** | Useful practice that may be adapted with a documented reason. |

When this handbook conflicts with upstream, upstream wins. Open [Source registry](./reference/source-registry), compare the pinned commit with the current repository, and update the handbook before relying on changed behavior.
