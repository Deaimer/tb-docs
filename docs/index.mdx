# Benches

This portal contains three independent benchmark manuals. Choose the benchmark before creating a task; formats, evidence requirements, validation logic, and submission routes are not interchangeable.

## Separation rule

Never reuse a task package unchanged across tracks.

| Track | Unit of work | Primary deliverable | Core evidence |
|---|---|---|---|
| Terminal-Bench | A self-contained terminal task | Harbor task directory | Oracle success, NOP failure, verifier soundness |
| Terminal-Bench-Science | A real scientific workflow | Harbor science task plus scientific evidence | Domain validity, provenance, numerical and scientific checks |
| SWE-bench | A repository issue at a fixed base commit | Structured instance and reproducible evaluation image | Gold patch, test patch, FAIL_TO_PASS and PASS_TO_PASS behavior |

## Working agreement

Authors work on personal branches derived from `authors`. Reviewers assess pull requests and prepare accepted changes on `reviewers`. Only the repository owner promotes reviewed material into `main`. The complete commands are under **Contributing**.
